Step 3 · Memory mapping

Read a file through a memory map

with TemporaryDirectory() as folder:
    path = Path(folder) / "values.npy"
    np.save(path, np.arange(1000, dtype=np.float64))
    mapped = np.load(path, mmap_mode="r",
                allow_pickle=False)
    first_chunk_mean = mapped[:100].mean()
    print("Mapped type:", type(mapped).__name__)
    print("First chunk mean:", first_chunk_mean)
    del mapped  # release before cleanup on Windows

File-backed storage

mmap_mode="r" maps the file read-only instead of loading it all.

Slices read what they need

mapped[:100] touches only the first 100 values.

The cell first imports Path from pathlib and TemporaryDirectory from tempfile, then saves 1000 float64 values to a small .npy file. Loading with mmap_mode="r" returns a numpy.memmap: an array whose storage is the file itself, opened read-only. Nothing is read in bulk up front; when we take mapped[:100] and its mean, only that part of the file is needed, and the mean of 0 to 99 is 49.5. allow_pickle=False is a safety habit for loading files. On Windows an open mapping keeps the file locked, so the notebook deletes mapped before the temporary directory is removed.
