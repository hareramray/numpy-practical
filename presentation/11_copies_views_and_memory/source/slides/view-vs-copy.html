This is the memory picture behind the previous slide. There is one buffer holding six integers. original describes all six cells; view describes cells 1 to 3 of the same buffer, marked by the blue bracket. When we write view[0] = 99, there is nothing to copy: the orange cell is the one both arrays see, so original[1] becomes 99 too. independent was created with .copy(), so it has its own dashed buffer holding 1, 2 and 3, and the write never reaches it. The two shares_memory checks from the notebook confirm the picture: True for the view, False for the copy. Try it: change independent and check that the top row stays the same.
