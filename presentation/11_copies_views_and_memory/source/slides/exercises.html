One copy, one view

Exercise 1

An independent copy of the first two rows of source

Expected: [[0, 1, 2], [3, 4, 5]], and it must not share memory with source.

safe_rows = source[:2].copy()

Exercise 2

Every second element, as a view

Expected: [0, 2, 4, 6, 8], and it must share memory with source_vector.

every_second = source_vector[::2]

Ask the audience to attempt both before revealing the code, which matches the reference solutions. In Exercise 1, source is np.arange(12).reshape(4, 3). The slice source[:2] chooses the first two rows, and .copy() separates their storage, so the check np.shares_memory(source, safe_rows) is False. Without .copy() the values would match but the memory check would fail. In Exercise 2, source_vector is np.arange(10). A step of 2 skips every other entry, and because this is basic slicing, the result is a view sharing the underlying buffer: in stride terms, its stride is simply twice the original's.
