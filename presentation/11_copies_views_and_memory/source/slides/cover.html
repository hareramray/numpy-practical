Strides, shared buffers, and memory-mapped files

Advanced

30–50 minutes

Prerequisites: notebooks 00–10

Welcome to notebook 11. Up to now we have treated arrays as values. Here we look underneath: an array is a description, made of a shape, a dtype and strides, that points into a block of memory called a buffer. Two arrays can point into the same buffer, so changing one changes the other. By the end you can predict when memory is shared, read strides, and work with a file through a memory map. The orange run on the cover is a slice view; the blue alternate cells are a stepped view of the same buffer.
