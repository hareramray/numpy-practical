Step 1 · Basic slicing shares data

Writing to a view edits the original

original = np.arange(6)
view = original[1:4]
independent = original[1:4].copy()
view[0] = 99
print("Original:", original)
print("Independent copy:", independent)
assert np.shares_memory(original, view)
assert not np.shares_memory(original, independent)
assert original[1] == 99

Original: [ 0 99  2  3  4  5]
Independent copy: [1 2 3]

NumPy course · 11 Copies and views

3

A view is a new array object that refers to an existing data buffer. Basic slicing with start, stop and step normally produces a view, so view[0] = 99 writes into the same memory as original[1], and printing original shows 99 in position 1. The .copy() call allocates new storage, so independent still holds [1 2 3]. np.shares_memory answers the question directly and is the right tool when you are unsure. Try it: modify independent, for example independent[0] = -1, and confirm that original stays unchanged.
