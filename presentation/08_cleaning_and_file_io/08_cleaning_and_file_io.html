Step 1 · Missing is not zero

Find what is missing or invalid

raw = np.array([[10., np.nan], [12., 20.], [np.inf, 22.]])
cleaned = raw.copy()
cleaned[~np.isfinite(cleaned)] = np.nan
print("Missing mask:\n", np.isnan(cleaned))
print("Column means ignoring missing:",
      np.nanmean(cleaned, axis=0))
assert np.isnan(cleaned).sum() == 2

3

NaN, not a number, marks a missing or undefined floating-point value. It has a strange property: NaN does not equal itself, so value == np.nan is always False and you must use np.isnan instead. np.isfinite is stricter still: it is False for NaN and for plus or minus infinity. Here we decide, as a data policy rather than a universal rule, that infinity is invalid too, so we copy the data and turn every non-finite entry into NaN. Then np.nanmean computes column means while skipping the holes: 10 and 12 give 11, 20 and 22 give 21. Try it: count missing entries by row and by column with np.isnan(cleaned).sum(axis=1) and sum(axis=0). You should get [1 0 1] for rows and [1 1] for columns.

Step 2 · Imputation with a stated assumption

Fill the gaps on purpose

if np.any(np.all(np.isnan(cleaned), axis=0)):
    raise ValueError("A column has no observed values")
column_means = np.nanmean(cleaned, axis=0)
imputed = np.where(np.isnan(cleaned), column_means, cleaned)
print(imputed)
assert np.isfinite(imputed).all()
np.testing.assert_allclose(imputed.mean(axis=0), column_means)

[[10. 21.]

Guard first

An all-missing column has no mean, so stop with an error.

where picks per cell

Missing: take the column mean. Else: keep the value.

State the policy

Mean filling keeps the mean but shrinks the spread.

5

Imputation means replacing missing values, and every imputation is an assumption you should state. Column-mean imputation is simple: it preserves each column's observed mean, which the final assert_allclose checks, but it changes the distribution and makes the data look less variable than it is. First we guard against a column that is entirely missing, because it has no observed mean to use; np.all along axis 0 detects that and we raise a clear error instead of silently producing NaN. np.where then works cell by cell: where the mask is True it takes the column mean, broadcast across rows, otherwise it keeps the original value. Try it: compare the standard deviation before and after filling. np.nanstd(cleaned, axis=0) gives [1. 1.], while imputed.std(axis=0) gives [0.8165 0.8165]: the filled values sit exactly at the mean, so the spread shrinks.

CSV, comma-separated values, is the most common way data arrives. np.genfromtxt parses simple numeric text and, unlike np.loadtxt, tolerates missing entries. StringIO lets us treat a Python string as if it were a file, so the example needs no file on disk. The right side shows what happens to the three lines of text: skip_header=1 drops the header line, delimiter="," splits each line into fields, and the empty field after 22 becomes nan. So genfromtxt hands you a float array with NaN already in place, ready for the detection and imputation steps you just learned.

Step 3 · CSV and NumPy binary formats

Save, load, and prove the round trip

with TemporaryDirectory() as folder:
    folder = Path(folder)
    np.savetxt(folder / "clean.csv", imputed, delimiter=",", header="a,b", comments="")
    from_csv = np.loadtxt(folder / "clean.csv", delimiter=",", skiprows=1)
    np.save(folder / "clean.npy", imputed)
    from_npy = np.load(folder / "clean.npy", allow_pickle=False)
    np.savez_compressed(folder / "bundle.npz", data=imputed, means=column_means)
    with np.load(folder / "bundle.npz", allow_pickle=False) as archive:
        print("Saved names:", archive.files)
        np.testing.assert_allclose(archive["data"], imputed)
    np.testing.assert_allclose(from_csv, imputed)
    np.testing.assert_array_equal(from_npy, imputed)

This cell writes the imputed array three ways and reads each one back. TemporaryDirectory gives a throwaway folder that is deleted when the with block ends, so the example is safe to rerun; swap in a Path of your choosing when you want files that persist. np.savetxt writes CSV text, with the header a,b and comments="" so the header line is not prefixed with a hash; np.loadtxt reads it back, skipping that header. np.save writes one array to a .npy file and np.load reads it; allow_pickle=False is a safety habit, so loading never runs arbitrary Python objects. np.savez_compressed stores several arrays by name in one .npz archive, and archive.files lists those names. Notice the checks: the CSV copy is compared with assert_allclose, because text can round, while the .npy copy passes the stricter assert_array_equal. Choose the format by who reads the file next. CSV is plain text: people, spreadsheets and other languages can open it, but it stores only digits and commas. The array's dtype is not kept, and floats are written as long decimal text such as 1.000000000000000000e+01. NumPy's .npy format stores one array in binary together with its dtype and shape, so it comes back exactly. .npz bundles several arrays under names, like data and means here, and savez_compressed zips them. The bottom row of each card is the Try it experiment: save the integer array [1, 2, 3] as .npy and np.load returns int64 again, while the same array written with savetxt and read back with loadtxt comes back as float64. The idea to remember

Missing is not zero.
Say how you fill it.

Detect gaps with isnan, fill them with a stated policy, and save arrays in a format that brings them back exactly.

Pause here. Treating a missing value as zero silently drags means down and invents data. The professional habit is a short chain: detect invalid values with isnan and isfinite, decide and write down a policy such as column-mean or median filling, check the result with asserts, and save the cleaned array as .npy or .npz so the next session starts from exactly the same numbers.

11

Give the audience time to attempt both before revealing the code, which matches the reference solutions. Exercise 1: np.isfinite builds an element mask, and all(axis=1) requires every entry in a row to be valid before that row is selected; the NaN row and the infinity row both drop out, leaving [[1, 2], [4, 5]]. This is dropping rather than filling, which is the other common policy. Exercise 2: np.nanmedian ignores the NaN and finds the median of 1, 3 and 9, which is 3; np.where then replaces only the missing entry, giving [1, 3, 3, 9]. The median is a sensible choice when a column may have outliers like 9.
