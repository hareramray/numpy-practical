Choose the format by who reads the file next. CSV is plain text: people, spreadsheets and other languages can open it, but it stores only digits and commas. The array's dtype is not kept, and floats are written as long decimal text such as 1.000000000000000000e+01. NumPy's .npy format stores one array in binary together with its dtype and shape, so it comes back exactly. .npz bundles several arrays under names, like data and means here, and savez_compressed zips them. The bottom row of each card is the Try it experiment: save the integer array [1, 2, 3] as .npy and np.load returns int64 again, while the same array written with savetxt and read back with loadtxt comes back as float64. Use CSV to share, .npy or .npz to resume work.
