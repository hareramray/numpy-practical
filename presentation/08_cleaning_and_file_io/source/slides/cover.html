Cleaning and file I/O

Missing values, imputation and saving arrays

Intermediate

30–50 minutes

Prerequisites: notebooks 00–07

Real data arrives with holes in it. This notebook teaches three habits: detect invalid values such as NaN and infinity, fill them with a policy you state out loud, and save your cleaned arrays so they come back exactly as you left them. The dashed cells in the cover grid are the missing values we will learn to find and fill. As always, the notebook creates its own data and uses temporary files, so it is safe to rerun.
