The challenge strings the whole notebook together. Write the CSV text yourself, so you know exactly where the two gaps are, then load it with np.genfromtxt and skip_header=1. Report missing counts per column with np.isnan(data).sum(axis=0) and check they total 2. Choose a filling policy, mean or median per column, and write it down in a markdown cell. Save the result with np.save, load it back with allow_pickle=False, and prove it with np.testing.assert_array_equal. There is no supplied check, so decide the expected filled values before you run anything. Then restart the kernel and run all cells once more.
