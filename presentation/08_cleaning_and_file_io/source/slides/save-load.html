This cell writes the imputed array three ways and reads each one back. TemporaryDirectory gives a throwaway folder that is deleted when the with block ends, so the example is safe to rerun; swap in a Path of your choosing when you want files that persist. np.savetxt writes CSV text, with the header a,b and comments="" so the header line is not prefixed with a hash; np.loadtxt reads it back, skipping that header. np.save writes one array to a .npy file and np.load reads it; allow_pickle=False is a safety habit, so loading never runs arbitrary Python objects. np.savez_compressed stores several arrays by name in one .npz archive, and archive.files lists those names. Notice the checks: the CSV copy is compared with assert_allclose, because text can round, while the .npy copy passes the stricter assert_array_equal. The only printed line is the archive's names; silence from the asserts means every round trip worked.
