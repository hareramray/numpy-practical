Walk through the three grids left to right. The raw 3 by 2 array has two problem cells, dashed: a NaN in row 0 and an infinity in row 2. The policy step uses the mask ~np.isfinite to turn both into NaN, so now there is a single kind of missing value. np.isnan then gives a Boolean grid of the same shape, True exactly where data is missing; that is the printed missing mask. Because the mask is just an array, everything from notebook 02 works on it: its sum counts missing cells, sum along an axis counts them per row or column. The bottom-left panel shows nanmean skipping the holes. The bottom-right panel is why we need isnan at all: comparing NaN with itself returns False.
