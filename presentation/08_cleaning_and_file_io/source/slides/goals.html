The notebook promises three things: detect invalid values, impute deliberately, and round-trip text and binary data. We split the file work into text and binary because they behave differently: CSV is easy to read and share but loses array details, while NumPy's own formats bring arrays back exactly. Prerequisites are notebooks 00 to 07; Boolean masks and np.where from earlier notebooks do most of the work here.
