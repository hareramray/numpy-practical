The challenge combines every step. Draw an array of shape (n, 2) from rng.uniform(0, 1, ...) so each row is a point in the unit square. The quarter circle x² + y² ≤ 1 covers pi/4 of that square, so the Boolean mean of the inside test estimates pi/4, and 4 times it estimates pi. Repeat with several seeds to see run-to-run variation, and with several sample sizes to see the spread shrink roughly like one over the square root of n. There is no supplied check: write your own, for example asserting the estimate is within a few standard errors of np.pi. Then restart the kernel and run all cells once more.
