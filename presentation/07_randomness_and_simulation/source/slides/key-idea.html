The idea to remember

Seed it. Repeat it.
Average it.

A seeded generator makes a simulation repeatable. Many random trials, averaged, estimate what one draw cannot.

Pause here. Everything in this notebook follows one recipe. Create one local generator with a seed so anyone can rerun your work and get the same numbers. Then run many trials as rows of an array and reduce along an axis: a Boolean mean for a probability, a quantile of means for a bootstrap interval. Remember that a seed buys reproducibility, not accuracy; accuracy comes from the number of trials and from representative data.
