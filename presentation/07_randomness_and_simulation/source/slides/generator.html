np.testing.assert_array_equal(a, b)

np.random.default_rng(seed) creates a Generator object that you pass around, rather than relying on hidden global state. One generator draws from many distributions: integers for dice, uniform for values between 0 and 1, normal for bell-shaped data around a mean of 170 with standard deviation 10. A seed makes the sequence reproducible for the same setup and calls; it does not make a small sample match its theoretical distribution, and exact values are not promised across arbitrary future NumPy versions. The last three lines prove reproducibility: two fresh generators with seed 123 give identical arrays, so the assert passes. Try it: run the rng cell twice, then run only a later sampling line twice. Re-running the whole cell repeats the same numbers because the generator is re-created; re-running one sampling line gives new numbers each time because the generator's state has advanced.
