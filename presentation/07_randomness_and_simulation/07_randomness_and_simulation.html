np.random.default_rng(seed) creates a Generator object that you pass around, rather than relying on hidden global state. One generator draws from many distributions: integers for dice, uniform for values between 0 and 1, normal for bell-shaped data around a mean of 170 with standard deviation 10. A seed makes the sequence reproducible for the same setup and calls; it does not make a small sample match its theoretical distribution, and exact values are not promised across arbitrary future NumPy versions. The last three lines prove reproducibility: two fresh generators with seed 123 give identical arrays, so the assert passes. Try it: run the rng cell twice, then run only a later sampling line twice. Re-running the whole cell repeats the same numbers because the generator is re-created; re-running one sampling line gives new numbers each time because the generator's state has advanced.

Step 2 · Monte Carlo probability

Estimate by repeated trials

rng = np.random.default_rng(7)
dice = rng.integers(1, 7, size=(50_000, 2))
event = dice.sum(axis=1) == 7
estimate = event.mean()
standard_error = np.sqrt(
    estimate * (1 - estimate) / event.size)
print("Estimated P(sum=7):", estimate)
print("Exact probability:", 6 / 36)
print("Estimated standard error:",
      standard_error)

Estimated P(sum=7): 0.16748
Exact probability: 0.16666666666666666
Estimated standard error: 0.0016699128695833207

One row, one trial

50,000 rows of two dice each.

Mean of a mask

True counts as 1, so the mean is the success rate.

Standard error

Typical sampling wobble, not a guarantee.

NumPy course · 07 Randomness and simulation

5

Monte Carlo estimates a quantity by running many random trials and averaging. Here each row is one trial of rolling two dice. dice.sum(axis=1) adds across each row, and comparing with 7 gives a Boolean event per trial. Because True counts as 1 and False as 0, event.mean() is the fraction of successes, which estimates the probability: 0.16748 against the exact 6/36, about 0.1667. The standard error, the square root of p(1 - p) / n, describes how much such an estimate typically varies from run to run; it is not a promise about any single run. Try it: rerun with 500 and with 50,000 trials. With 100 times fewer trials the standard error is about 10 times larger (with seed 7 and 500 trials the estimate was 0.138, standard error about 0.015), but do not expect every larger sample to land closer to the truth.

Step 3 · Bootstrap a sample mean

Bootstrap: resample your own data

observed = np.array([12., 14., 9., 15.,
                     13., 11., 18., 16.])
rng = np.random.default_rng(10)
resampled = rng.choice(observed,
    size=(2_000, observed.size), replace=True)
bootstrap_means = resampled.mean(axis=1)
interval = np.quantile(bootstrap_means,
                       [0.025, 0.975])
print("Observed mean:", observed.mean())
print("Illustrative 95% percentile"
      " interval:", interval)

Observed mean: 13.5
Illustrative 95% percentile interval: [11.75 15.375]

With replacement

A value can be drawn more than once.

Same size rows

2,000 new samples of 8 values each.

Quantiles, interval

The middle 95% of the means.

NumPy course · 07 Randomness and simulation

7

The bootstrap asks: if we could collect this sample again, how much would its mean move? We cannot collect new data, so we resample the data we have, with replacement. rng.choice with size (2000, 8) builds 2,000 new rows, each the same size as the original sample. Taking the mean along axis 1 gives 2,000 bootstrap means, and the 2.5% and 97.5% quantiles of those means give a simple percentile interval: 11.75 to 15.375 around the observed mean of 13.5. This assumes independent, representative observations; resampling cannot repair biased data. Try it: plot bootstrap_means with plt.hist to see the bell-like spread, and try a larger observed sample: with more data, the histogram and the interval get narrower.

The idea to remember

Seed it. Repeat it.
Average it.

A seeded generator makes a simulation repeatable. Many random trials, averaged, estimate what one draw cannot.

Pause here. Everything in this notebook follows one recipe. Create one local generator with a seed so anyone can rerun your work and get the same numbers. Then run many trials as rows of an array and reduce along an axis: a Boolean mean for a probability, a quantile of means for a bootstrap interval. Remember that a seed buys reproducibility, not accuracy; accuracy comes from the number of trials and from representative data.
