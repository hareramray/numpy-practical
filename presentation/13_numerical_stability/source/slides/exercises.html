Ask the audience to attempt both before revealing the code lines, which match the reference solutions. Exercise 1: log1p computes the small logarithmic change without first rounding 1 + x to a nearby representable value. Note that the reference run prints [0. 0. 0.] only because the notebook sets np.set_printoptions(suppress=True), which displays tiny numbers as 0; the stored values are about 1e-16, 1e-12 and 1e-8, and the check with rtol 1e-12 passes. Exercise 2: subtracting the maximum makes both shifted scores zero, their exponentials are both 1, and normalizing gives equal weights of 0.5. A naive exp(10000) would be inf and the result nan.
