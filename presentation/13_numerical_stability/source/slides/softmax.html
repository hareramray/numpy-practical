Step 3 · Stable softmax

Subtract the max, then exp

def softmax(scores):
    scores = np.asarray(scores, dtype=np.float64)
    shifted = scores - scores.max(axis=-1, keepdims=True)
    exponentials = np.exp(shifted)
    return exponentials / exponentials.sum(
        axis=-1, keepdims=True)

scores = np.array([[1000., 1001., 1002.],
                   [-1000., -1000., -999.]])
probabilities = softmax(scores)
print(probabilities)

Softmax turns any finite scores into positive weights that sum to one: exponentiate each score, then divide by the row total. Exponentials grow fast, so scores near 1000 overflow float64. Subtracting the row maximum first changes nothing mathematically, because the same factor cancels in the numerator and denominator, but now the largest exponent is exp(0) = 1. The notebook's asserts confirm that every value is finite, each row sums to 1, and shifting all scores by 500 gives the same probabilities. Very negative shifted scores can still underflow to 0, which is usually harmless.
