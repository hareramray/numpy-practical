The challenge has no supplied check: decide what you expect before you run anything. A good dataset mixes one large value, such as 1e8, with many small ones, such as a million values of 1, all stored as float32. With float32 accumulation, small values added to a large running total can be rounded away, because float32 keeps only about 7 significant digits; passing dtype=np.float64 to sum accumulates in double precision and keeps them. NumPy's pairwise summation reduces this error, so the order and grouping of your data affect how big the difference is.
