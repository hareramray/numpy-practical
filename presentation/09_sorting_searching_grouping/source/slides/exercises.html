Sum amounts by integer group code

group_totals = np.bincount(codes,

Let the audience try both before revealing the code, which matches the reference solutions. Exercise 1: sorting the negated marks gives descending indices, here [1, 3, 0, 2]; slicing the first two and indexing students with them keeps names aligned with marks, giving B with 90 and D with 85. Exercise 2: the codes are already integers, so no np.unique step is needed. bincount adds each amount to the slot for its code: code 0 gets 2 plus 3, code 1 gets 5 plus 1, code 2 gets 7, giving [5. 6. 7.]. minlength=3 guarantees all three group positions exist even if a code were missing.
