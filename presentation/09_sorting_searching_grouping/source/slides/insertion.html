An insertion position is a gap, not a cell. Five elements have six gaps, numbered 0 to 5, shown under the row. To insert another 20 while keeping order, there are two valid gaps: just before the first 20, gap 1, which side="left" returns, and just after the last 20, gap 3, which side="right" returns. Everything between those two gaps is a run of equal values, so right minus left counts the copies of 20: two. That trick counts occurrences in sorted data without scanning. The bottom panel is the Try it: searchsorted for 25 also returns 3, because 25 belongs between 20 and 30. To test membership you must also check that sorted_values at that position equals the value you searched for; here it is 30, so 25 is absent.
