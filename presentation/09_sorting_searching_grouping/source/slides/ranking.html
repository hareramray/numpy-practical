Read the picture left to right. On the left is the original data with each row's index. argsort of the negated scores returns order = [1, 0, 2, 3]: the blue column. Read it as instructions: the first place goes to row 1, then row 0, then row 2, then row 3. Indexing names with order and scores with the same order produces the ranking on the right, Ben 95, Asha 82, Chen 82, Divya 70, which is exactly the printed output, and the name and score in each row still belong together. The two orange cells are the tie: because the sort is stable, the student who came first in the input, Asha at index 0, stays ahead of Chen at index 2. Ask the audience what order = argsort(-scores) would look like if Chen were listed before Asha in the input.
