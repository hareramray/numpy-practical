Sort, search and group

argsort, searchsorted and grouped totals

Intermediate

30–50 minutes

Prerequisites: notebooks 00–08

This notebook is about putting data in order and summarising it. You will sort related arrays so they stay aligned, find where a value belongs in sorted data, count distinct labels, and compute group totals and means with plain NumPy, no pandas needed. The common thread is working with positions and integer codes rather than with the values themselves.
