NumPy course · 12 Vectorization

The challenge has no supplied check: write your own. Generate a 2D array with a seeded generator, write a loop that computes the square root of the sum of squares for each row, and a vectorized version such as np.sqrt((X ** 2).sum(axis=1)) or np.linalg.norm(X, axis=1). Prove they agree with assert_allclose before timing anything, then use timeit.repeat as in Step 2 and report the shape and dtype. For the memory part, note that X ** 2 creates a temporary as large as X, while the row sums are only one value per row. Finish by restarting the kernel and running all cells.
