These four habits turn "NumPy is fast" from a slogan into engineering. First make sure the fast version gives the same answer as a simple one. Then measure speed with repeated timings rather than a single run. Finally, remember that array expressions allocate temporary arrays: reusing buffers and processing chunks keep memory use under control when data gets large.
