Exercise 1

Sum of squares for each row, without a Python loop

features is [[1, 2, 3], [4, 5, 6]]. Expected: [14, 77].

row_energy = (features ** 2).sum(axis=1)

Exercise 2

Implement f(x) = 3x + 2 with array operations

inputs is [0, 1, 2, 3, 4]. Expected: [2, 5, 8, 11, 14].

transformed = 3 * inputs + 2

Ask the audience to attempt both before revealing the code, which matches the reference solutions. In Exercise 1, squaring every feature and summing across the columns with axis=1 leaves one energy value per row: 1 + 4 + 9 = 14 and 16 + 25 + 36 = 77. In Exercise 2, inputs is np.arange(5, dtype=float), and the scalar multiplication and addition broadcast across the whole array, giving [2, 5, 8, 11, 14]. Neither answer needs a Python loop, and each is one line that runs in compiled code.
