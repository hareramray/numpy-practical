Step 2 · Lists, loops, and functions

Just enough Python to start

prices = [10, 20, 30]
print("First price:", prices[0])
discounted = [p * 0.9 for p in prices]

def total_with_tax(values, tax_rate=0.05):
    return sum(values) * (1 + tax_rate)

print(discounted)
print(total_with_tax(prices))

First price: 10
[9.0, 18.0, 27.0]
63.0

Indexing starts at 0

prices[0] is the first item, 10.

Loops repeat work

The comprehension builds a new list, one price at a time.

Functions name a calculation

return sends the result back. Indentation is part of the syntax.

5

This is the first big idea of the course. The usual import is import numpy as np. A list times 2 gives a list twice as long: the dashed cells are the repeated copy. An array times 2 keeps the same length and doubles each value. NumPy applies arithmetic elementwise, with no loop written by you. The notebook confirms this with np.testing.assert_array_equal(values * 2, [20, 40, 60]).

Step 3 · Read an error

Read an error from its last line

values = np.array([10, 20, 30])
try:
    print(values[99])
except IndexError as error:
    print("Intentional error:", error)

Intentional error: index 99 is out
of bounds for axis 0 with size 3

IndexError

What kind of problem happened.

index 99

What you asked for.

size 3

What exists: valid indices are 0, 1 and 2.

The idea to remember

Lists repeat.
Arrays compute.

A NumPy array applies one operation to every element at once. The rest of the course builds on that.

Pause here. Everything from notebook 01 onwards (dtypes, broadcasting, statistics, linear algebra) is a variation on this one behaviour: write the operation once, and NumPy applies it across the whole array in fast compiled code.

Two warm-up exercises

Exercise 1

Total minutes for 25 minutes a day over 6 days

Expected: 150. Plain scalar arithmetic: daily duration times days.

practice_minutes = 25 * 6

Exercise 2

Convert [0, 10, 20] °C to Fahrenheit

Expected: [32, 50, 68]. The formula F = C × 9/5 + 32 runs on every element at once.

fahrenheit = celsius * 9 / 5 + 32
