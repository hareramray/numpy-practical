Filtering in the frequency domain takes three moves. Copy the spectrum so the original stays intact. Use the boolean mask frequencies > 10 to set every coefficient above 10 Hz to zero, which removes the 40 Hz component. Then np.fft.irfft converts the edited spectrum back into samples; passing n=signal.size guarantees the original length, which matters for odd-length signals. The first assert proves the result is the pure 5 Hz sine, and the second proves that the unedited spectrum round-trips to the original signal. This is an ideal cutoff, fine for a learning example; for other signals an abrupt cutoff can cause ringing, and real filter design also considers boundaries and transients. Try it: set the cutoff to 50 Hz. Both 5 Hz and 40 Hz now survive, so irfft recovers the original signal.
