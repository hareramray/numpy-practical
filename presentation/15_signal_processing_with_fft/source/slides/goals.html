The notebook's goal: build a sampled signal, identify frequency peaks, and reconstruct a filtered signal. We work with a signal whose ingredients we already know, a 5 Hz sine plus a weaker 40 Hz sine, so every result can be checked against the truth. That is a useful habit with any new tool: test it on input where you know the right answer before trusting it on real data such as audio, vibration or sensor readings.
