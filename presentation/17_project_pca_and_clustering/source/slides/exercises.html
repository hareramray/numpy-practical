Ask the audience to attempt both before revealing the code lines, which match the reference solutions. Exercise 1: all three orthonormal principal directions span the full feature space, so projecting onto them and projecting back reconstructs Z exactly, up to rounding; compare this with the 0.008 error from keeping two. Exercise 2: np.bincount counts how many observations carry each non-negative label. Without minlength=3, an empty last cluster would silently shorten the result to length 2, so minlength keeps a slot for every cluster.
