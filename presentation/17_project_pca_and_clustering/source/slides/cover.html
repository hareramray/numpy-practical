PCA and k-means project

From NumPy building blocks: the finale

Capstone / expert practice

60–90 minutes

Prerequisites: 00–14

The last notebook of the course, and the second capstone. We build two classic data-science tools from scratch with NumPy alone: principal component analysis, which finds the directions in which data varies most, and k-means, which groups nearby observations. No scikit-learn: every step is broadcasting, reductions, linear algebra and indexing you already know. The picture at right is the goal in miniature: three groups of points, each with a centroid ring. By the end you will have a checked, reusable k-means loop and a 2-D view of 3-D data.
