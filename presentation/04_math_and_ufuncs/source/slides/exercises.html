Two elementwise exercises

Exercise 1

Areas of circles with radii [1., 2., 3.]

Expected: π × [1, 4, 9], printed as [ 3.1416 12.5664 28.2743]. Squaring is elementwise.

areas = np.pi * radii ** 2

Exercise 2

Replace negative inventory with zero

From [3, -2, 7, -1, 0], expected [3 0 7 0 0]. A lower bound of 0; None leaves the top open.

clean_inventory = np.clip(
    inventory, 0, None)

Ask the audience to attempt both before revealing the code lines, which match the reference solutions. Exercise 1: the power operator squares each radius independently, and np.pi is the NumPy constant, so each radius gets its own area. Exercise 2: np.clip with a lower bound of zero raises the negative entries to zero, and passing None as the upper bound leaves large values unbounded. np.where(inventory < 0, 0, inventory) and np.maximum(inventory, 0) also pass the check, because the checks verify the result, not the method.
