The idea to remember

Write it once.
Every cell obeys.

Operators and ufuncs run on every element. clip, np.where and where= decide, cell by cell, what is computed and kept.

Pause here. Everything in this notebook is elementwise: the operation is written once and applied to each position of the array. The only question you control is what happens at each cell, and the three tools answer it: clip bounds a value, np.where chooses between two values, and a ufunc's where= decides whether a value is computed at all. Broadcasting, next, extends the same idea to arrays of different shapes.
