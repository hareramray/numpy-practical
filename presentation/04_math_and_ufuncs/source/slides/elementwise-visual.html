This is the same calculation drawn as cells. Each column is one product: the quantity cell multiplies only the price cell directly beneath it, and the blue result cell lands in the same position. No loop is written; NumPy pairs the positions for you, which is why both arrays must line up. On the right, a ufunc takes one array and transforms each cell independently: the square roots of 1, 4 and 9 are 1, 2 and 3. Ask the audience to predict each blue cell before revealing it.
