Step 2 · Boolean masks

A comparison makes a mask

marks = np.array([45, 62, 78, 90, 55, 84])
mask = (marks >= 60) & (marks < 85)
print("Mask:", mask)
print("Selected:", marks[mask])
print("Positions:", np.flatnonzero(mask))
assert np.count_nonzero(mask) == 3

Not and / or

Python's and cannot combine arrays elementwise.

NumPy course · 02 Indexing and filtering

6

A comparison such as marks >= 60 does not return one True or False: it returns a Boolean array with one answer per element. Indexing with that mask keeps the entries where it is True. To combine conditions use & for and, | for or, and ~ for not, and put each comparison in parentheses, because & has higher precedence than the comparison operators. Python's and keyword tries to turn the whole array into a single truth value and raises an error. np.flatnonzero reports where the True values are, and np.count_nonzero counts them, here 3. Try it: select marks below 50 or at least 85 with marks[(marks < 50) | (marks >= 85)]. Expect [45 90].
