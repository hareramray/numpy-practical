Selections also work on the left side of an assignment. adjusted < 4 is True for the values 0, 1, 2 and 3, which all sit in row 0, so those four cells, shown in orange, become -1 while every other value stays put. Assign through one indexing expression, as here, to change the original array; the notebook works on adjusted, a copy, so that table itself is left unchanged for later cells.
