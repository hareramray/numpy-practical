Read this slide top to bottom, one column at a time. Each comparison produces its own row of True and False, one per mark. The & operator combines them position by position: the result is True only where both rows are True, which happens at positions 1, 2 and 5. 90 fails the second condition and 45 and 55 fail the first. Indexing marks with the mask keeps exactly the orange values, 62, 78 and 84, and drops the rest; the result is a new, shorter 1D array. Try it: redraw the bottom rows for (marks < 50) | (marks >= 85). With or, a position needs only one True: positions 0 and 3, giving [45 90].
