Step 1 · Indexing and slicing

Row first, then column

scores = np.array([[65, 80, 90], [75, 60, 85],
                   [95, 88, 92], [50, 70, 68]])
print("Last student's last score:", scores[-1, -1])
print("First two students:\n", scores[:2])
print("Second subject:", scores[:, 1])

a[row, column]

One position per axis, separated by a comma.

start:stop:step

stop is excluded; a missing start or stop means the edge.

Negative indices

Count from the end: -1 is the last row or column.

scores is a table of 4 students (rows, axis 0) by 3 subjects (columns, axis 1). For a 2D array, write one index per axis inside a single pair of brackets: scores[-1, -1] is the last row and last column, 68. scores[:2] gives only a row slice, so all columns come along: rows 0 and 1, because the stop 2 is excluded. scores[:, 1] means every row, column 1, the second subject. Try it: select the last two students and the first two subjects with scores[-2:, :2]. Expect [[95 88] [50 70]], shape (2, 2).
