This is the whole broadcasting rule. Write the two shapes one above the other, aligned on the right. Compare each column of dimensions: they are compatible if they are equal or one of them is 1, and a missing leading dimension counts as 1. The result takes the larger size in each column. Left: (3, 2) with (2,) compares 2 with 2, then 3 with a missing axis, so the result is (3, 2). Right: (3, 2) with (3,) compares 2 with 3, and neither is 1, so NumPy raises an error. Inserting an axis with [:, None] turns the discounts into a (3, 1) column, which fits. Try it: predict (4, 1, 3) with (2, 3). Aligned right: 3 and 3, then 1 and 2 give 2, then 4 stays, so np.broadcast_shapes returns (4, 2, 3).

Step 1 · Align dimensions from the right

One rate per column, every row

prices = np.array([[100., 200.],
                  [150., 250.], [80., 120.]])
tax_rate = np.array([0.05, 0.10])
print("Shapes:", prices.shape, tax_rate.shape)
print("Taxed prices:\n",
      prices * (1 + tax_rate))

(3, 2) times (2,)

One tax rate per column, reused on every row.

No tiling in your code

NumPy reuses the row; you never repeat it by hand.

Results still need memory

Broadcasting avoids repeating inputs, not the output.

4

Three customers are rows and two products are columns. The tax rates have shape (2,), one per product. Aligned from the right, 2 matches 2 and the missing row axis acts as 1, so the rates are reused for every customer: 100 becomes 105 at 5 percent and 200 becomes 220 at 10 percent. You never build a 3 by 2 array of rates; NumPy behaves as if the row were repeated. The full (3, 2) result is still allocated, so broadcasting saves input copies, not output memory. The notebook also subtracts one discount per customer using discount_by_customer[:, None], which the next slide draws.

Step 2 · Center columns and rows

Subtract the mean, keep the axis

data = np.array([[1., 10.], [3., 20.], [5., 30.]])
centered_columns = data - data.mean(axis=0, keepdims=True)
centered_rows = data - data.mean(axis=1, keepdims=True)
print(centered_columns)
print(centered_rows)

 [  2.  10.]]
[[ -4.5   4.5]
 [ -8.5   8.5]
 [-12.5  12.5]]

axis=0: per column

Means have shape (1, 2) and stretch down the rows.

axis=1: per row

Means have shape (3, 1) and stretch across the columns.

keepdims=True

Keeps the reduced axis as length 1, so alignment is explicit.

Centering means subtracting a mean so the result averages to zero. Column means, axis=0, are 3 and 20; subtracting them centres each feature, giving the first printed table. Row means, axis=1, are 5.5, 11.5 and 17.5; subtracting them gives the second table, where every row is now symmetric around zero. keepdims=True leaves the reduced axis in place with length 1, so the means come back as (1, 2) or (3, 1) and line up with the (3, 2) data. The notebook then asserts that the new column and row means are zero within 1e-12. Try it: remove keepdims from the row calculation. The row means become shape (3,), which aligns against the last axis of length 2, and the subtraction fails. That is the next slide.

Step 3 · Pairwise differences

A column minus a row: every pair

x = np.array([1., 4., 7.])
y = np.array([2., 5.])
differences = x[:, None] - y[None, :]
print(differences)
distances = np.abs(differences)
assert distances.shape == (3, 2)
np.testing.assert_allclose(distances,
    [[1, 4], [2, 1], [5, 2]])

[[-1. -4.]
 [ 2. -1.]
 [ 5.  2.]]

x[:, None] is (3, 1)

The x values become a column.

y[None, :] is (1, 2)

The y values become a row.

The result is (3, 2)

Row i, column j holds x[i] − y[j]: an outer operation.

NumPy course · 05 Broadcasting

8

Indexing with None inserts a new axis of length 1. x[:, None] turns the three x values into a (3, 1) column and y[None, :] turns the two y values into a (1, 2) row. Aligned from the right, 1 meets 2 and 3 meets 1, so both stretch and the result is (3, 2): one entry for every combination of an x and a y. For example, row 2, column 0 is 7 minus 2, which is 5. Taking np.abs gives distances. This pattern is called an outer operation. Write the shape beside each intermediate before you scale up, because a large column times a large row can need a lot of memory. Try it: make x and y 2D points, for example shapes (3, 2) and (2, 2), compute x[:, None, :] - y[None, :, :] of shape (3, 2, 2), square it, sum over the last axis, and take the square root to get distances of shape (3, 2).

The idea to remember

Align right.
Ones stretch.

Compare shapes from the last axis: each pair equal, or one of them 1. Write the shape beside every step.

Pause here. Every broadcasting question is answered by the same check: line the shapes up on the right, and each pair of dimensions must be equal or contain a 1. A length-1 axis, whether it comes from keepdims, from indexing with None, or from a missing leading dimension, is the axis that stretches. When a calculation surprises you, write the shape of every intermediate array; the mistake is almost always visible there.

The challenge combines broadcasting with notebook 04's safe division. Column minimums and maximums come from min and max with axis=0 and keepdims=True, giving (1, 3) rows that stretch down the four rows. Scaled values are (X - min) divided by (max - min). A constant column has a range of zero, so use np.divide with a zero-filled out buffer and where= set to range != 0; that column then stays at zero. Check your result: every non-constant column should have a minimum of 0 and a maximum of 1. Then restart the kernel and run all cells once more.
