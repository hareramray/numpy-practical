An illustration with simple numbers: a column a = [[0], [10], [20]] of shape (3, 1) plus a row b = [[1, 2, 3, 4]] of shape (1, 4). Aligned from the right, 1 meets 4 and 3 meets 1, so the result is (3, 4). The column is reused across all four columns and the row is reused down all three rows, as the dashed cells show, and each result cell is a[i] + b[j]: row 1, column 2 is 10 + 3 = 13. Twelve results from seven stored numbers. The notebook's pairwise differences are exactly this pattern with subtraction and smaller sizes, (3, 1) minus (1, 2) giving (3, 2). Exercise 2, the multiplication table, is the same pattern again with a (5, 1) column times a (1, 5) row.
