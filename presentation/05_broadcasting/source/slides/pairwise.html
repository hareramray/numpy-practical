A column minus a row: every pair

x = np.array([1., 4., 7.])
y = np.array([2., 5.])
differences = x[:, None] - y[None, :]

distances = np.abs(differences)

Indexing with None inserts a new axis of length 1. x[:, None] turns the three x values into a (3, 1) column and y[None, :] turns the two y values into a (1, 2) row. Aligned from the right, 1 meets 2 and 3 meets 1, so both stretch and the result is (3, 2): one entry for every combination of an x and a y. For example, row 2, column 0 is 7 minus 2, which is 5. Taking np.abs gives distances. This pattern is called an outer operation. Write the shape beside each intermediate before you scale up, because a large column times a large row can need a lot of memory. Try it: make x and y 2D points, for example shapes (3, 2) and (2, 2), compute x[:, None, :] - y[None, :, :] of shape (3, 2, 2), square it, sum over the last axis, and take the square root to get distances of shape (3, 2).
