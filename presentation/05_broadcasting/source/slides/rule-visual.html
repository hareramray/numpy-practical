This is the whole broadcasting rule. Write the two shapes one above the other, aligned on the right. Compare each column of dimensions: they are compatible if they are equal or one of them is 1, and a missing leading dimension counts as 1. The result takes the larger size in each column. Left: (3, 2) with (2,) compares 2 with 2, then 3 with a missing axis, so the result is (3, 2). Right: (3, 2) with (3,) compares 2 with 3, and neither is 1, so NumPy raises an error. Inserting an axis with [:, None] turns the discounts into a (3, 1) column, which fits. Try it: predict (4, 1, 3) with (2, 3). Aligned right: 3 and 3, then 1 and 2 give 2, then 4 stays, so np.broadcast_shapes returns (4, 2, 3).
