Two broadcasting exercises

Exercise 1

Add one offset per row of a (2, 3) matrix

Offsets [10, 20]. Expected: [[11 12 13] [24 25 26]]. The offsets must become a (2, 1) column.

shifted = matrix + offsets[:, None]

Exercise 2

The 1–5 multiplication table, shape (5, 5)

Expected first row [1 2 3 4 5], last row [5 10 15 20 25]. A column times a row.

times_table = (numbers[:, None]
              * numbers[None, :])

Ask the audience to write the shapes first, then the code. Exercise 1: matrix is (2, 3) and offsets is (2,). Added directly, 3 would meet 2 and fail; inserting a length-1 column axis makes offsets (2, 1), so each row receives its own offset, 10 for the first row and 20 for the second. Exercise 2: numbers is np.arange(1, 6). A (5, 1) column times a (1, 5) row broadcasts to all 25 products, the same outer pattern as the pairwise differences. The code lines match the reference solutions; the parentheses only wrap the line.
