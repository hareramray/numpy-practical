Here the three updates are drawn as chips: two of them, outlined in orange, target the same position 0. With buffered fancy indexing, NumPy gathers buffered[[0, 0, 2]] into a temporary array, [0, 0, 0], adds [1, 1, 5] to get [1, 1, 5], and scatters the result back. Position 0 is written twice with the value 1, so the final array is [1, 0, 5]: one of the two increments is lost, and no error is raised. np.add.at does the addition in place for each occurrence, so position 0 goes 0, then 1, then 2, giving [2, 0, 5]. This matters for histograms, group sums and scatter operations, where repeated indices are the normal case, not the exception.
