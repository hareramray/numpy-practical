The challenge has no supplied check: write your own. A Gram matrix of a 3 × 2 matrix X is X transposed times X, which is 2 × 2. For a batch, swapaxes(-1, -2) transposes only the last two axes, and @ broadcasts over the leading batch axis, so the result has shape (4, 2, 2). The einsum version names every axis: "bij,bik->bjk" keeps the batch axis b, sums over the shared row axis i, and keeps j and k. Compare the two with np.testing.assert_allclose. Each Gram matrix should also be symmetric, which is a second check worth adding. Then restart the kernel and run all cells.
