Step 2 · Rolling windows as views

Overlapping windows, no copies

from numpy.lib.stride_tricks import sliding_window_view
signal = np.array([1., 2., 3., 4., 5., 6.])
windows = sliding_window_view(signal, window_shape=3)
rolling_mean = windows.mean(axis=-1)
print(windows)
print("Rolling means:", rolling_mean)
assert not windows.flags.writeable
assert np.shares_memory(signal, windows)

sliding_window_view returns a new array whose last axis runs along each window. A window of width w over n values gives n - w + 1 complete windows, here 6 - 3 + 1 = 4, so the shape is (4, 3). It is a view built with strides, as in notebook 11: no window is copied, which the shares_memory assert confirms. Because the windows overlap, one element appears in several windows, so NumPy makes the view read-only to stop a write from changing several windows at once. Reducing still touches every window entry, so for long rolling sums a cumulative-sum trick can be cheaper. Try it: compute windows.min(axis=-1) and windows.max(axis=-1), giving [1, 2, 3, 4] and [3, 4, 5, 6]; each result belongs at the last index of its window, positions 2 to 5 of signal.
