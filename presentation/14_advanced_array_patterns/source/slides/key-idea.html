The idea to remember

Name the axes.
View, don't copy.
Count every repeat.

einsum says which axes survive and which are summed; windows are views; np.add.at applies every repeated index.

Pause here. The three tools share a theme: say precisely what you mean, and NumPy does the work without hidden surprises. einsum makes every axis explicit, so a contraction reads like its formula. sliding_window_view reuses memory instead of copying overlapping data. np.add.at removes the silent data loss of buffered fancy-index updates. In each case the notebook verified the new tool against a familiar one, and that habit is the real lesson.
