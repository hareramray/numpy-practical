4

Map each letter to an axis length. In A, i has length 2 and j has length 3; in B, j has length 3 and k has length 4. The shared letter j must have the same length in both, just like the inner dimensions of a matrix product. The output keeps i and k, so its shape is (2, 4). Each output element multiplies along j and adds: for product[0, 0], the blue row of A, 0, 1, 2, meets the blue column of B, 0, 4, 8, giving 0 + 4 + 16 = 20, the first value the notebook printed. Changing the output letters changes the operation: ij,jk->ki would give the transposed product, and ij,jk-> with nothing after the arrow would sum everything to one number.
