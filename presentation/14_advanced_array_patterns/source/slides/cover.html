Welcome to notebook 14. It introduces three patterns that experienced NumPy users reach for: einsum, which writes sums of products by naming axes; sliding_window_view, which gives overlapping windows without copying data; and np.add.at, which accumulates correctly when the same index appears more than once. Each solves a problem that is awkward or subtly wrong with the basic tools. As always, the notebook imports its own libraries and creates its own data.
