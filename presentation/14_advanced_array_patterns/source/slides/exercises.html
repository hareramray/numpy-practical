Two exercises on the patterns

Exercise 1

One dot product per pair of matching rows, with einsum

left = [[1, 2], [3, 4]], right = [[5, 6], [7, 8]]. Expected: [17, 53].

row_dots = np.einsum("ij,ij->i",
                     left, right)

Exercise 2

Valid rolling means with window width 2

series = [2, 4, 8, 10]. Expected: [3, 6, 9], one mean per complete pair.

rolling = sliding_window_view(
    series, 2).mean(axis=-1)

Ask the audience to attempt both before revealing the code lines, which match the reference solutions. Exercise 1: the label i survives as the row axis, and the repeated j label is summed, giving a dot product for each corresponding row pair: 1·5 + 2·6 = 17 and 3·7 + 4·8 = 53. The reference run prints [17. 53.]. Exercise 2: the window view exposes adjacent pairs, (2, 4), (4, 8) and (8, 10), and averaging the final axis gives one mean per complete pair; the reference run prints [3. 6. 9.]. Four values with width 2 give 4 - 2 + 1 = 3 windows.
