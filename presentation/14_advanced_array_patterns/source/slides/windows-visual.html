Each row is one window: the blue cells are the three signal values it sees, shifted one step to the right each time. The staircase shows the overlap: the value 3 belongs to three windows, yet it is stored only once in memory, because every window is a view into the same six numbers. Averaging along the last axis turns each blue row into one orange mean, 2, 3, 4 and 5, exactly the notebook's rolling means. Only complete windows are produced, so the result is shorter than the signal by w - 1 values. If you need an output aligned with the original, pad the front with NaN or align each mean with the last index of its window.
