Step 3 · Concatenate versus stack

Two ways to join arrays

a, b = np.array([1, 2, 3]), np.array([4, 5, 6])
print("Concatenate:", np.concatenate([a, b]))
print("Stack rows:\n", np.stack([a, b], axis=0))
print("Stack columns:\n", np.stack([a, b], axis=1))

Concatenate: [1 2 3 4 5 6]
Stack rows:
 [[1 2 3]
 [4 5 6]]
Stack columns:
 [[1 4]
 [2 5]
 [3 6]]

concatenate

Joins along an existing axis. Other axis lengths must match.

stack

Adds a new axis. Inputs must have equal shapes.

array_split

Splits into uneven pieces; split needs equal ones.

NumPy course · 03 Shapes and axes

8

The notebook defines a and b on two lines; they are combined here to save space. concatenate joins arrays along an axis they already have: two length-3 vectors placed end to end give one length-6 vector, so no dimension is added. stack creates a brand-new axis and places the inputs along it: axis=0 makes each input a row, giving shape (2, 3), and axis=1 makes each input a column, giving shape (3, 2). Because stack lines the inputs up element by element, they must have exactly the same shape. Try it: stack three length-4 arrays. Predict first: axis=0 gives shape (3, 4) and axis=1 gives shape (4, 3).
