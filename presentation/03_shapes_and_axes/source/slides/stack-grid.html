NumPy course · 03 Shapes and axes

9

Blue cells come from a and orange cells from b. concatenate puts them end to end on their existing single axis, so the result is still 1D, now of length 6. stack adds a new axis: with axis=0 the new axis comes first, so a and b become the two rows; with axis=1 the new axis comes last, so they become the two columns, which is the same as stacking rows and then transposing. The bottom row shows splitting, the reverse operation: array_split divides 7 values into 3 pieces as evenly as it can, giving sizes 3, 2 and 2. np.split(np.arange(7), 3) would raise an error, because 7 does not divide into 3 equal pieces.
