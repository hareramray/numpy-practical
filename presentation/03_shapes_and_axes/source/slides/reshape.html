Step 1 · Reshape preserves the count

A shape is a contract

values = np.arange(12)
table = values.reshape(3, 4)
print(table)
print("Column shape:", values[:, None].shape)
print("Row shape:", values[None, :].shape)
assert table.size == values.size

Same values

3 × 4 = 12, so reshape(3, 4) is allowed.

-1 means infer

One length may be -1; NumPy computes it.

None adds an axis

A 1D vector becomes a column (12, 1) or a row (1, 12).

NumPy course · 03 Shapes and axes

3

A shape is a contract about how values are arranged; reshape changes the arrangement but never adds or removes values. The product of the new lengths must equal the size: 12 values fit 3 by 4, 2 by 6 or 12 by 1, but not 5 by anything. One length may be -1 and NumPy works it out from the others. A 1D vector has a single axis, with no separate row and column; indexing with None inserts a new axis of length 1, which turns it into an explicit column (12, 1) or row (1, 12). The assert confirms the size is unchanged. Try it: run values.reshape(5, -1) inside try/except. It raises ValueError, because 12 is not divisible by 5, so no whole number of columns works.
