This is the map for the whole session. The four solid stages are worked in the notebook's three steps; the dashed export stage is yours, in the independent challenge. Every stage passes the same array forward, so a mistake early, such as treating a missing count as zero, silently flows into every later number. That is why each stage ends with an assertion: the cube keeps shape (30, 3, 4), revenue is finite, and store totals, product totals and daily totals all add up to the same grand total.
