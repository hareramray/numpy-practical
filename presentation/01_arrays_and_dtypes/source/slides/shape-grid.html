This is the sales table from the previous slide drawn as a grid. For a table, axis 0 runs down through the rows and axis 1 runs across through the columns, and the shape lists them in that order: (2, 3) means 2 along axis 0 and 3 along axis 1. ndim is simply the number of entries in the shape tuple, and size is their product, 2 times 3 equals 6. Because every element is int64, which uses 8 bytes, nbytes is 6 times 8, 48. Ask the audience: if we add a row, which number in the shape changes? Only the first, giving (3, 3).
