Exercise 1

A 3 × 4 array filled with 2.5, using float64

Expected: shape (3, 4), dtype float64, every value 2.5. full takes the shape and the fill value.

filled = np.full((3, 4), 2.5,
                dtype=np.float64)

Exercise 2

An integer array of 5, 10, 15, 20, 25

Expected: [5, 10, 15, 20, 25] with an integer dtype. arange excludes its stop, so stop at 26 to include 25.

multiples = np.arange(5, 26, 5)

Let the audience attempt both before revealing the code, which matches the reference solutions. Exercise 1's check asserts shape (3, 4), dtype float64 and every value close to 2.5; writing the dtype explicitly guarantees the fractional part is preserved. Exercise 2's check compares the values and uses np.issubdtype(multiples.dtype, np.integer), so any integer dtype passes. A common mistake is np.arange(5, 25, 5), which stops at 20 because the stop value is excluded. np.array([5, 10, 15, 20, 25]) would also pass: the check verifies the result, not the method.
