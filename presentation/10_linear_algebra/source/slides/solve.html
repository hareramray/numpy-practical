Step 2 · Solve equations

Solve A x = b, then check it

A = np.array([[2., 1.], [1., 3.]])
b = np.array([5., 7.])
x = np.linalg.solve(A, b)
print("Solution:", x)
print("Residual norm:", np.linalg.norm(A @ x - b))
print("Condition number:", np.linalg.cond(A))
np.testing.assert_allclose(A @ x, b)

A x = b is two equations with two unknowns: 2 x1 + x2 = 5 and x1 + 3 x2 = 7. np.linalg.solve finds x = [1.6, 1.8]. Never trust a solution blindly: the residual A @ x minus b measures how well the answer satisfies the equations, and its norm here is exactly 0.0. The condition number measures sensitivity. A value near 1 is ideal; nearly dependent columns push it towards infinity, and then tiny changes in b can produce large changes in x. Try it: make both rows of A identical. The matrix becomes singular, and solve raises numpy.linalg.LinAlgError, which you can catch with try and except.
