Exercise 1

Solve system @ solution = target

system is [[3, 1], [1, 2]] and target is [9, 8]. Expected: [2, 3].

solution = np.linalg.solve(
    system, target)

Exercise 2

Fit y = intercept + slope·x by least squares

The data follow y = 4 + 3x exactly, so expect [4, 3]. Columns are ones, then x.

line_parameters = np.linalg.lstsq(
    X_fit, y_fit, rcond=None)[0]

Ask the audience to attempt both before revealing the code, which matches the reference solutions. Exercise 1 is a square, full-rank system, so solve finds the unknown vector directly, and substituting [2, 3] back gives 3 times 2 plus 3, which is 9, and 2 plus 2 times 3, which is 8. The check also tests system @ solution against target. In Exercise 2, X_fit already holds a column of ones and a column of x values, so the coefficient order is intercept then slope. lstsq returns a tuple with the coefficients first, which is why the solution takes element [0]. Because the data are noise-free, the fit is exact within 1e-12.
